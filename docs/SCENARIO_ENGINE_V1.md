# Scenario Engine v1

Scenario Engine converts supported Human Model dimension pairs into cautious,
recognizable behavior sequences. It does not predict events and does not claim
that a scenario has already happened.

Pipeline:

Natal chart → Human Model → Scenario Engine → AI writer → PDF

Each scenario includes:
- supported theme;
- typical trigger;
- possible reaction sequence;
- resource;
- point to watch;
- traceable astrological evidence.

Version 1 contains five rules and returns at most four strongest scenarios.
