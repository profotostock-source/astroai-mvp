## Report Components

### Page 1: Cover Page
- Title and subtitle
- User name
- Generation date
- Professional appearance

### Page 2: Interpretations & Profile
The heart of the user-friendly report

**Profile Section**:
- Table format with user data
- Quick reference for birth information
- Three key signs displayed

**Psychological Portrait**:
- AI-generated 200-300 word summary
- Explains Sun, Moon, and Ascendant roles
- Personalized insight into personality

**Sun Sign Interpretation**:
- Represents: Core identity and life energy
- Strengths: 3-4 positive qualities
- Challenges: 2-3 potential issues
- Advice: 1-2 actionable recommendations

**Moon Sign Interpretation**:
- Represents: Emotional nature and inner needs
- Strengths: 3-4 emotional strengths
- Challenges: 2-3 emotional challenges
- Advice: 1-2 emotional recommendations

**Ascendant Interpretation**:
- Represents: How others perceive you
- Strengths: 3-4 external qualities
- Challenges: 2-3 external challenges
- Advice: 1-2 social recommendations

### Page 3+: Technical Data
Professional technical reference

**Core Signs Table**:
- Compact display of Sun, Moon, Ascendant
- Three key indicators at a glance

**Planets Table**:
- All 10 planets with signs
- Exact degrees
- Retrograde status
- Ukrainian translations

**Houses Table** (if time known):
- All 12 houses with signs
- Exact degrees
- (Empty if time unknown)

**Aspects Table**:
- All significant planetary aspects
- Planet pairs
- Aspect type (Conjunction, Square, Trine, etc.)
- Orb precision

**Warnings Section**:
- Any calculation notes
- Missing data explanations
- Data quality notices

**Disclaimer**:
- Legal protection
- Clarification of purpose
- Non-medical notice

## Design Philosophy

✨ **User-Centric**
- Readable sections with clear hierarchy
- Important information first (interpretations)
- Technical details after (for reference)

✨ **Professional**
- Clean formatting
- Consistent styling
- Ukrainian typography

✨ **Informative**
- Psychological insight combined with technical data
- Balanced interpretation and facts
- Educational value

✨ **Accessible**
- Multiple pages prevent clutter
- Page breaks for readability
- Clear section headings
- Table formatting for data

---

## Report Generation Process

1. **User Input** → Birth data collected via Telegram bot
2. **Calculation** → Astrology calculations via Kerykeion
3. **Interpretation** → Signs matched with descriptions
4. **Portrait** → AI generates psychological summary
5. **PDF Creation** → ReportLab generates multi-page PDF
6. **Delivery** → PDF sent to user via Telegram

---

## Customization Points

The upgrade supports easy customization:

1. **Interpretations**: Edit `services/interpretations.py`
   - Modify existing descriptions
   - Add new signs/planets

2. **Styling**: Modify `services/pdf.py`
   - Font sizes in `_build_styles()`
   - Colors in table definitions
   - Spacing with `Spacer()` elements

3. **Sections**: Modify `_build_astrology_section()`
   - Reorder sections
   - Add/remove components
   - Change page breaks

4. **AI Portraits**: Modify `get_psychological_portrait()`
   - Change template
   - Adjust length
   - Add more personality factors
